# Maison Rose Cleaning Co. 🌹

Maison Rose Cleaning Co. is a fictional luxury residential cleaning company website created as a front-end web development portfolio project.

The project was designed and developed from the ground up as a responsive, multi-page website focused on elegant design, usability, accessibility, performance, and foundational SEO.

## Features

- Responsive multi-page website
- Mobile-friendly navigation
- Custom quote request form
- Contact form with validation
- Responsive image galleries
- Accessible navigation and form structure
- Optimized WebP images
- Foundational on-page SEO
- Performance and accessibility optimization
- Cross-device testing

## Pages

- Home
- About
- Services
- Request a Quote
- Contact

## Built With

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Google Fonts

## Performance & Accessibility

The website was tested and optimized using Google Lighthouse, including reviews for:

- Performance
- Accessibility
- Best Practices
- SEO
- Color contrast
- Image optimization
- Mobile responsiveness
- Core Web Vitals

## Project Purpose

This website was created to demonstrate my ability to design and develop a complete custom website for a service-based business without relying on website-builder templates.

## Disclaimer

Maison Rose Cleaning Co. is a fictional business created for portfolio and educational purposes. Testimonials, contact information, and business details shown on the website are sample content.
